**Recetas verificadas de IEEE-CIS Fraud (2019):**

```
MOD_INGEST:
- Pandas con dtype optimization (category, int8/16/32)
- Memory reduction de 650MB → ~150MB

MOD_SIGNAL:
- Group Aggregations jerárquicas: groupby(['card_id', 'addr']) 
  → agg(['mean', 'std', 'count', 'nunique'])
- Client-side aggregations: mean/max/min de TransactionAmt por card1
- Time features: day_of_week, hour (cíclico sin/ cos)
- Email domain matching: P_emaildomain == R_emaildomain → binary

MOD_SPLIT:
- Adversarial Validation: entrenar LightGBM para clasificar train vs test
  → AUC alto = covariate shift detectado
  → Feature importance identifica variables shifted → drop o re-sample

MOD_ARCH:
- LightGBM con categorical_feature support nativo
- XGBoost con target encoding pre-computado
- CatBoost para cat features de alta cardinalidad

MOD_LOSS:
- Binary cross-entropy con scale_pos_weight
- Focal loss para desbalance extremo

MOD_ENSEMBLE:
- Rank averaging entre modelos
- Seed averaging (5 seeds × 3 modelos = 15 modelos)

WHAT_DIDNT_WORK:
- Deep learning (NN) en tabular → LB peor que GBDT
- Interacciones polinómicas de alto grado → overfitting masivo
- One-hot encoding de alta cardinalidad → explosion dimensional
```

```python
# MOD_INGEST: DICOM → PNG pipeline
import pydicom
import numpy as np
from PIL import Image

def dicom_to_png(dicom_path, output_path, size=1536):
    ds = pydicom.dcmread(dicom_path)
    pixel_array = ds.pixel_array.astype(np.float32)
    # Normalize to 16-bit
    pixel_array = (pixel_array - pixel_array.min()) / (pixel_array.max() - pixel_array.min()) * 65535
    # Resize with aspect ratio preservation
    img = Image.fromarray(pixel_array.astype(np.uint16))
    img = img.resize((size, size), Image.LANCZOS)
    img.save(output_path, format='PNG')

# MOD_LOSS: Focal Loss
import torch
import torch.nn.functional as F

class FocalLoss(nn.Module):
    def __init__(self, alpha=0.25, gamma=2.0):
        super().__init__()
        self.alpha = alpha
        self.gamma = gamma
    
    def forward(self, pred, target):
        bce = F.binary_cross_entropy_with_logits(pred, target, reduction='none')
        p_t = torch.exp(-bce)
        loss = self.alpha * (1 - p_t)**self.gamma * bce
        return loss.mean()

# MOD_ENSEMBLE: TTA with horizontal flip
def predict_with_tta(model, image):
    pred_orig = model(image)
    pred_flip = model(torch.flip(image, dims=[-1]))  # horizontal flip
    return (pred_orig + pred_flip) / 2
```

```python
# MOD_SIGNAL: Target Encoding with smoothing
def target_encode_smoothing(train, test, col, target, n_folds=5, smoothing=20):
    train[f'{col}_te'] = 0
    test[f'{col}_te'] = 0
    
    kf = KFold(n_splits=n_folds)
    for tr_idx, val_idx in kf.split(train):
        tr, val = train.iloc[tr_idx], train.iloc[val_idx]
        
        # Calculate smoothed mean
        global_mean = tr[target].mean()
        agg = tr.groupby(col)[target].agg(['mean', 'count'])
        smooth = (agg['count'] * agg['mean'] + smoothing * global_mean) / (agg['count'] + smoothing)
        
        train.loc[train.index[val_idx], f'{col}_te'] = val[col].map(smooth).fillna(global_mean)
    
    # Apply to test
    global_mean = train[target].mean()
    agg = train.groupby(col)[target].agg(['mean', 'count'])
    smooth = (agg['count'] * agg['mean'] + smoothing * global_mean) / (agg['count'] + smoothing)
    test[f'{col}_te'] = test[col].map(smooth).fillna(global_mean)
    
    # Add Gaussian noise
    noise = np.random.normal(0, 0.01, len(train))
    train[f'{col}_te'] += noise
    
    return train, test
```
